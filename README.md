# Parking-Allocation
Parking Allocation Recommendation using Deep Learning Models like MobileNetV3 and Efficient-Net

Download the dataset from http://cnrpark.it/#:~:text=CNRPark%2BEXT%20is%20a%20dataset,lot%20of%20164%20parking%20spaces.

On navigating to the website, download: CNRPark-Patches-150x150.zip (36.6 MB), CNR-EXT-Patches-150x150.zip (449.5 MB), CNR-EXT_FULL_IMAGE_1000x750.tar (1.1 GB)

Close the repositpry from Github, or download the repository. Run app.py, and add path of image for free parking space detection from the EXT_FULL_IMAGE_1000x750.tar folder, add camera angle. Automation is possible. 

Bounding Box will display the free parking spot available in the parking lot.
